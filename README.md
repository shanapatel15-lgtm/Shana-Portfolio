# Shana Patel — Software Engineer Portfolio

A personal developer portfolio showcasing my software engineering experience, technical skills, projects and continued learning across full-stack development, cloud engineering and AI-powered applications.

The website is designed to provide recruiters, hiring managers and other developers with an overview of my background and the technologies I work with.

## ✨ Features

* **Responsive design** — adapts to desktop, tablet and mobile screens.
* **About me** — introduces my engineering background and interests.
* **Project showcase** — highlights personal and professional software projects.
* **Technical skills** — covers backend development, frontend technologies, cloud infrastructure and AI.
* **Professional experience** — summarises my software engineering experience at Fujitsu.
* **Contact section** — provides links for professional networking and enquiries.
* **Interactive navigation** — includes mobile navigation and active section highlighting.
* **Dark visual theme** — uses a modern design with gradient accents and custom CSS illustrations.
